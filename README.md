# HR Analytics Dashboard (Power BI)

## Project Overview

This project presents an interactive HR Analytics Dashboard built using Power BI to analyze workforce data and support better HR decision-making.

The dashboard provides insights into employee demographics, attendance patterns, salary costs, performance evaluation, recruitment efficiency, and employee attrition.

---

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Modeling
* Data Visualization

---

## Dashboard Pages

### 1. HR Overview

Provides a summary of total employees, active employees, resigned employees, employee demographics, and department distribution.

### 2. Attendance Analysis

Analyzes attendance performance, absenteeism trends, leave records, and department-level attendance insights.

### 3. Salary Analysis

Tracks payroll expenses, salary distribution, bonuses, deductions, and salary comparisons across departments.

### 4. Performance Analysis

Evaluates employee performance scores, commitment levels, and identifies high/low performance patterns.

### 5. Recruitment Analysis

Measures hiring performance, recruitment costs, hiring rates, and applicant-to-hire trends.

### 6. Attrition Analysis

Examines employee turnover, resignation reasons, attrition rate, and departments with higher employee exits.
